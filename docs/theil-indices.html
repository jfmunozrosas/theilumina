Theil indices

Definition, decomposition and estimation

Modified

November 16, 2026

Definition

Let Y be a positive random variable with mean \mu = E[Y]. The Theil indices are members of the generalised entropy family GE(\alpha):

T_1 = GE(1) = E\left[\frac{Y}{\mu}\log\frac{Y}{\mu}\right], \qquad T_0 = GE(0) = E\left[\log\frac{\mu}{Y}\right] = \log\mu - E[\log Y].

T_1 is the Theil index and T_0 the mean logarithmic deviation (MLD). Both are zero under perfect equality and increase with inequality. T_1 is more sensitive to the upper tail of the distribution, and T_0 to the lower tail.

Closed forms for common distributions

Distribution T_0 T_1
Lognormal (\mu_{\log}, \sigma) \sigma^2/2 \sigma^2/2
Pareto (x_m, \alpha), \alpha>1 \log\frac{\alpha}{\alpha-1} - \frac{1}{\alpha} \frac{1}{\alpha-1} - \log\frac{\alpha}{\alpha-1}
Gamma (k, \theta) \log k - \psi(k) \psi(k) + \frac{1}{k} - \log k

where \psi(\cdot) is the digamma function.

Additive decomposition

If the population is partitioned into G groups with population shares p_g, income shares s_g, means \mu_g and indices T_{0g}, T_{1g}:

T_1 = \underbrace{\sum_{g=1}^{G} s_g\, T_{1g}}_{\text{within}} + \underbrace{\sum_{g=1}^{G} s_g \log\frac{\mu_g}{\mu}}_{\text{between}}, \qquad T_0 = \underbrace{\sum_{g=1}^{G} p_g\, T_{0g}}_{\text{within}} + \underbrace{\sum_{g=1}^{G} p_g \log\frac{\mu}{\mu_g}}_{\text{between}}.

This property makes the Theil indices the standard tool to identify the sources of inequality: by region, gender, age, education, sector, type of employment or municipality size.

Plug-in estimators

Given a sample y_1,\dots,y_n with mean \bar y:

\widehat{T}_1 = \frac{1}{n}\sum_{i=1}^{n}\frac{y_i}{\bar y}\log\frac{y_i}{\bar y} = \frac{\sum_i y_i\log y_i}{\sum_i y_i} - \log\bar y, \qquad \widehat{T}_0 = \log\bar y - \frac{1}{n}\sum_{i=1}^{n}\log y_i . 

T1.hat <- function(y) {
  m <- mean(y)
  mean((y / m) * log(y / m))
}

T0.hat <- function(y) {
  log(mean(y)) - mean(log(y))
}

These estimators are consistent but biased in finite samples. The bias is negligible for symmetric, low-inequality data, but becomes severe under strong skewness and inequality. See the interactive bias explorer.

Jackknife bias correction and variance

Let \widehat{T}_{(i)} be the estimator computed without observation i, and \widehat{T}_{(\cdot)} = n^{-1}\sum_i \widehat{T}_{(i)}. The jackknife bias-corrected estimator and variance estimator are

\widehat{T}^{\,J} = n\,\widehat{T} - (n-1)\,\widehat{T}_{(\cdot)}, \qquad \widehat{V}_J = \frac{n-1}{n}\sum_{i=1}^{n}\left(\widehat{T}_{(i)} - \widehat{T}_{(\cdot)}\right)^2 .

The standard implementation recomputes the index n times, with cost O(n^2). Because \widehat{T}_0 and \widehat{T}_1 depend on the data only through a few sums, every leave-one-out value can be obtained by subtracting observation i from those sums, with cost O(n):

# Leave-one-out values in O(n)
T.loo <- function(y, index = c("T1", "T0")) {
  index <- match.arg(index)
  n  <- length(y)
  Sy <- sum(y)
  m.i <- (Sy - y) / (n - 1)                      # leave-one-out means
  if (index == "T1") {
    Sylogy <- sum(y * log(y))
    (Sylogy - y * log(y)) / (Sy - y) - log(m.i)
  } else {
    Slogy <- sum(log(y))
    log(m.i) - (Slogy - log(y)) / (n - 1)
  }
}

jackknife.theil <- function(y, index = c("T1", "T0")) {
  index <- match.arg(index)
  n   <- length(y)
  est <- if (index == "T1") T1.hat(y) else T0.hat(y)
  loo <- T.loo(y, index)
  m.loo <- mean(loo)
  list(estimate  = est,
       corrected = n * est - (n - 1) * m.loo,
       variance  = (n - 1) / n * sum((loo - m.loo)^2))   # two-pass
}

These functions will be part of the R package theil, developed in WP4.

## Definition

Let $Y$ be a positive random variable with mean $\mu = E[Y]$. The Theil indices are members of the generalised entropy family $GE(\alpha)$:

$$
T_1 = GE(1) = E\left[\frac{Y}{\mu}\log\frac{Y}{\mu}\right],
\qquad
T_0 = GE(0) = E\left[\log\frac{\mu}{Y}\right] = \log\mu - E[\log Y].
$$

$T_1$ is the **Theil index** and $T_0$ the **mean logarithmic deviation** (MLD). Both are zero under perfect equality and increase with inequality. $T_1$ is more sensitive to the upper tail of the distribution, and $T_0$ to the lower tail.

### Closed forms for common distributions

| Distribution | $T_0$ | $T_1$ |
|---|---|---|
| Lognormal $(\mu_{\log}, \sigma)$ | $\sigma^2/2$ | $\sigma^2/2$ |
| Pareto $(x_m, \alpha)$, $\alpha>1$ | $\log\frac{\alpha}{\alpha-1} - \frac{1}{\alpha}$ | $\frac{1}{\alpha-1} - \log\frac{\alpha}{\alpha-1}$ |
| Gamma $(k, \theta)$ | $\log k - \psi(k)$ | $\psi(k) + \frac{1}{k} - \log k$ |

where $\psi(\cdot)$ is the digamma function.

## Additive decomposition

If the population is partitioned into $G$ groups with population shares $p_g$, income shares $s_g$, means $\mu_g$ and indices $T_{0g}$, $T_{1g}$:

$$
T_1 = \underbrace{\sum_{g=1}^{G} s_g\, T_{1g}}_{\text{within}} + \underbrace{\sum_{g=1}^{G} s_g \log\frac{\mu_g}{\mu}}_{\text{between}},
\qquad
T_0 = \underbrace{\sum_{g=1}^{G} p_g\, T_{0g}}_{\text{within}} + \underbrace{\sum_{g=1}^{G} p_g \log\frac{\mu}{\mu_g}}_{\text{between}}.
$$

This property makes the Theil indices the standard tool to identify the **sources** of inequality: by region, gender, age, education, sector, type of employment or municipality size.

## Plug-in estimators

Given a sample $y_1,\dots,y_n$ with mean $\bar y$:

$$
\widehat{T}_1 = \frac{1}{n}\sum_{i=1}^{n}\frac{y_i}{\bar y}\log\frac{y_i}{\bar y}
= \frac{\sum_i y_i\log y_i}{\sum_i y_i} - \log\bar y,
\qquad
\widehat{T}_0 = \log\bar y - \frac{1}{n}\sum_{i=1}^{n}\log y_i .
$$

```r
T1.hat <- function(y) {
  m <- mean(y)
  mean((y / m) * log(y / m))
}

T0.hat <- function(y) {
  log(mean(y)) - mean(log(y))
}
```

These estimators are consistent but biased in finite samples. The bias is negligible for symmetric, low-inequality data, but becomes severe under strong skewness and inequality. See the [interactive bias explorer](simulation.qmd).

## Jackknife bias correction and variance

Let $\widehat{T}_{(i)}$ be the estimator computed without observation $i$, and $\widehat{T}_{(\cdot)} = n^{-1}\sum_i \widehat{T}_{(i)}$. The jackknife bias-corrected estimator and variance estimator are

$$
\widehat{T}^{\,J} = n\,\widehat{T} - (n-1)\,\widehat{T}_{(\cdot)},
\qquad
\widehat{V}_J = \frac{n-1}{n}\sum_{i=1}^{n}\left(\widehat{T}_{(i)} - \widehat{T}_{(\cdot)}\right)^2 .
$$

The standard implementation recomputes the index $n$ times, with cost $O(n^2)$. Because $\widehat{T}_0$ and $\widehat{T}_1$ depend on the data only through a few sums, every leave-one-out value can be obtained by subtracting observation $i$ from those sums, with cost $O(n)$:

```r
# Leave-one-out values in O(n)
T.loo <- function(y, index = c("T1", "T0")) {
  index <- match.arg(index)
  n  <- length(y)
  Sy <- sum(y)
  m.i <- (Sy - y) / (n - 1)                      # leave-one-out means
  if (index == "T1") {
    Sylogy <- sum(y * log(y))
    (Sylogy - y * log(y)) / (Sy - y) - log(m.i)
  } else {
    Slogy <- sum(log(y))
    log(m.i) - (Slogy - log(y)) / (n - 1)
  }
}

jackknife.theil <- function(y, index = c("T1", "T0")) {
  index <- match.arg(index)
  n   <- length(y)

       corrected = n * est - (n - 1) * m.loo,
       variance  = (n - 1) / n * sum((loo - m.loo)^2))   # two-pass
}
```
