Introducción

Esta guía muestra cómo estimar los índices de Theil en R, cómo descomponerlos entre grupos y dentro de ellos, y cómo medir su sesgo y su precisión. Todo el código usa R base o paquetes disponibles hoy en CRAN.

Los dos índices de Theil pertenecen a la familia de entropía generalizada GE(\alpha):

  • T_1 (índice de Theil T, GE(1)): es más sensible a lo que ocurre en la parte alta de la distribución.
  • T_0 (desviación logarítmica media o MLD, GE(0)): es más sensible a la parte baja.

Ambos valen 0 con igualdad perfecta, cumplen el principio de transferencias de Pigou-Dalton, no dependen de la escala de la renta y, sobre todo, son aditivamente descomponibles. La desigualdad total es exactamente la suma de una parte entre grupos (regiones, sexo, sectores) y otra dentro de ellos. Esta propiedad, que el índice de Gini no tiene, es la razón principal para usarlos.

El paquete de R theil de THEILUMINA reunirá en una sola herramienta la estimación, la corrección del sesgo y la inferencia. Mientras tanto, esta guía usa las funciones que ya existen.

Fórmulas

Sea una muestra de rentas positivas y_1, \dots, y_n con pesos muestrales w_i y media ponderada \mu. Sin pesos, basta con tomar w_i = 1.

T_1 = \frac{\sum_i w_i \frac{y_i}{\mu}\ln\frac{y_i}{\mu}}{\sum_i w_i}, \qquad T_0 = \frac{\sum_i w_i \ln\frac{\mu}{y_i}}{\sum_i w_i}, \qquad \mu = \frac{\sum_i w_i y_i}{\sum_i w_i}

Con G grupos, donde p_g es la proporción de población del grupo g, \mu_g su media y s_g = p_g \mu_g / \mu su proporción de renta, las descomposiciones son:

T_1 = \underbrace{\sum_g s_g\, T_{1,g}}_{\text{dentro}} + \underbrace{\sum_g s_g \ln\frac{\mu_g}{\mu}}_{\text{entre}}, \qquad T_0 = \underbrace{\sum_g p_g\, T_{0,g}}_{\text{dentro}} + \underbrace{\sum_g p_g \ln\frac{\mu}{\mu_g}}_{\text{entre}}

En T_1 la desigualdad dentro de cada grupo se pondera por su peso en la renta; en T_0, por su peso en la población. Por eso T_0 es el índice preferido cuando se quiere que cada persona cuente lo mismo, y la única descomposición en la que la parte «entre» no depende de la desigualdad dentro de los grupos.

Ambos índices requieren rentas estrictamente positivas: los logaritmos no admiten ceros ni valores negativos.

Estimación en R

Con R base

Dos funciones de pocas líneas bastan, con pesos opcionales:

theil_T1 <- function(y, w = rep(1, length(y))) {
  stopifnot(all(y > 0))
  mu <- weighted.mean(y, w)
  r  <- y / mu
  sum(w * r * log(r)) / sum(w)
}

theil_T0 <- function(y, w = rep(1, length(y))) {
  stopifnot(all(y > 0))
  mu <- weighted.mean(y, w)
  sum(w * log(mu / y)) / sum(w)
}

y <- c(10, 20, 30, 40, 60, 80)
theil_T1(y)   # 0.1809
theil_T0(y)   # 0.2114

Con paquetes de CRAN

Paquete T_1 T_0 Pesos Descomposición Errores estándar

convey svygei(~y, des, epsilon = 1) svygei(~y, des, epsilon = 0) Diseño muestral svygeidec() Sí, por linealización

Cuidado con ineq: en Theil(), parameter = 0 devuelve T_1 y cualquier otro valor devuelve T_0, al revés de lo que sugiere la notación GE(\alpha). Además, para T_1 elimina en silencio las rentas nulas. Compruébalo siempre con el ejemplo anterior.

library(ineq)
Theil(y, parameter = 0)   # 0.1809 -> T1
Theil(y, parameter = 1)   # 0.2114 -> T0

library(dineq)
w <- c(2, 1, 1, 1, 1, 3)
theil.wtd(y, weights = w) # 0.2125
mld.wtd(y, weights = w)   # 0.2710

Con datos de encuesta (ECV/EU-SILC), convey es la opción más completa, porque tiene en cuenta el diseño muestral al calcular los errores estándar:

library(survey); library(convey)
des <- svydesign(ids = ~psu, strata = ~estrato, weights = ~peso, data = ecv)
des <- convey_prep(des)
svygei(~renta_eq, des, epsilon = 0)   # T0 con su error estándar
svygei(~renta_eq, des, epsilon = 1)   # T1 con su error estándar

Los nombres de los argumentos pueden cambiar entre versiones. Antes de usar una función, consulta su ayuda (?decompGEI, ?svygeidec, ?iq_theil). El paquete iIneq calcula la contribución individual de cada observación a T_0 y T_1 y a sus descomposiciones. Ninguno de estos paquetes corrige el sesgo de los estimadores.

Descomposición entre y dentro de grupos

En el ejemplo, dos regiones explican el 72 % de la desigualdad total según T_1 y el 68 % según T_0. Esta función aplica las fórmulas anteriores a cualquier variable de grupo:

theil_decomp <- function(y, g, w = rep(1, length(y)), tipo = c("T1", "T0")) {
  tipo <- match.arg(tipo)
  mu  <- weighted.mean(y, w)
  grp <- split(seq_along(y), g)
  res <- t(sapply(grp, function(i) {
    p   <- sum(w[i]) / sum(w)              # proporción de población
    mug <- weighted.mean(y[i], w[i])       # media del grupo
    s   <- p * mug / mu                    # proporción de renta
    Tg  <- if (tipo == "T1") theil_T1(y[i], w[i]) else theil_T0(y[i], w[i])
    if (tipo == "T1") c(p = p, s = s, T_g = Tg, dentro = s * Tg, entre = s * log(mug / mu))
    else              c(p = p, s = s, T_g = Tg, dentro = p * Tg, entre = p * log(mu / mug))
  }))
  W <- sum(res[, "dentro"]); B <- sum(res[, "entre"])
  list(grupos = res,
       resumen = c(total = W + B, dentro = W, entre = B, pct_entre = 100 * B / (W + B)))
}

g <- c("A", "A", "A", "B", "B", "B")
theil_decomp(y, g, tipo = "T1")$resumen
theil_decomp(y, g, tipo = "T0")$resumen
Índice Total Dentro Entre % entre
T_1 0,1809 0,0501 0,1308 72,3 %
T_0 0,2114 0,0676 0,1438 68,0 %

En ambos casos dentro + entre reproduce exactamente el total, lo que sirve como comprobación. Con paquetes, el mismo resultado se obtiene con dineq::theil_decomp(y, g, w) y dineq::mld_decomp(y, g, w), con IC2::decompGEI(y, g, w, alpha = 1), o con convey::svygeidec(~y, ~g, des, epsilon = 1) si hay diseño muestral.

Ejemplo completo: renta por regiones

Este ejemplo simula rentas log-normales en cuatro regiones con medias y dispersiones distintas, calcula los dos índices, los descompone y representa la contribución de cada región. Los valores exactos dependen de la semilla; lo que importa es la interpretación.

set.seed(2026)
regiones <- data.frame(
  region = c("Norte", "Sur", "Este", "Oeste"),
  n      = c(400, 300, 200, 100),
  media  = c(9.9, 9.5, 10.1, 9.7),   # media de log(renta)
  sd     = c(0.5, 0.7, 0.6, 0.4)
)
datos <- do.call(rbind, lapply(seq_len(nrow(regiones)), function(k) {
  with(regiones[k, ], data.frame(region = region,
                                 renta  = rlnorm(n, meanlog = media, sdlog = sd)))
}))

# Índices globales
theil_T1(datos$renta)
theil_T0(datos$renta)

# Descomposición por región
dT0 <- theil_decomp(datos$renta, datos$region, tipo = "T0")
round(dT0$grupos, 4)
round(dT0$resumen, 4)

# Contribución de cada región a la desigualdad "dentro"
library(ggplot2)
contrib <- data.frame(region = rownames(dT0$grupos),
                      dentro = dT0$grupos[, "dentro"])
ggplot(contrib, aes(reorder(region, dentro), dentro)) +
  geom_col(fill = "#E07B20") + coord_flip() +
  labs(x = NULL, y = "Contribución a T0 (dentro de regiones)")

Cómo leer el resultado:

  • pct_entre indica qué parte de la desigualdad se debe a que las regiones tienen rentas medias distintas. Una política de convergencia regional solo puede actuar sobre esa parte.
  • La columna dentro muestra qué regiones aportan más desigualdad interna. Depende tanto de su desigualdad propia (T_g) como de su tamaño (p).
  • Si T_1 y T_0 dan mensajes distintos, la desigualdad se concentra en colas diferentes: T_1 reacciona a la parte alta y T_0 a la parte baja.

Ejemplo: descomposición por sexo

En este ejemplo, la brecha entre mujeres y hombres explica alrededor del 23 % de la desigualdad total; el 77 % restante se debe a la desigualdad dentro de cada sexo. Los datos son diez rentas (en miles de euros), cinco de mujeres y cinco de hombres:

renta <- c(12, 15, 18, 22, 30,   # mujeres
           16, 20, 25, 35, 50)   # hombres
sexo  <- rep(c("Mujer", "Hombre"), each = 5)

d1 <- theil_decomp(renta, sexo, tipo = "T1")
d0 <- theil_decomp(renta, sexo, tipo = "T0")
round(d0$grupos, 4)
round(rbind(T1 = d1$resumen, T0 = d0$resumen), 4)

Cómo leerlo:

  • La parte entre mide cuánta desigualdad desaparecería si mujeres y hombres tuvieran la misma renta media. Es la medida de la brecha de género que ofrecen los índices de Theil.
  • La parte dentro indica que, aun cerrando la brecha, quedaría la mayor parte de la desigualdad, sobre todo entre los hombres (índice del grupo 0,083 frente a 0,050).
  • Con datos de encuesta, la misma descomposición con su error estándar se obtiene con convey::svygeidec(~renta, ~sexo, des, epsilon = 0). Es lo que permite decir si la brecha ha cambiado de verdad entre dos años.

La variable de grupo puede ser cualquier otra: discapacidad, nacionalidad, nivel educativo, o cruces como sexo × región (interaction(sexo, region)). Cuantos más grupos, más pequeños son y mayor es el sesgo, como se explica en la sección siguiente.

Sesgo y precisión

Los estimadores muestrales de T_0 y T_1 tienen sesgo, que suele ser a la baja y es mayor en muestras pequeñas y con distribuciones de cola pesada. Por eso no deberían publicarse sin una medida de su precisión. El jackknife da a la vez una estimación del sesgo y del error estándar:

\widehat{\text{sesgo}} = (n-1)\,(\bar T_{(\cdot)} - \hat T), \qquad \tilde T = \hat T - \widehat{\text{sesgo}}, \qquad \widehat{\text{Var}} = \frac{n-1}{n}\sum_i \big(\hat T_{(i)} - \bar T_{(\cdot)}\big)^2

Calcular los n índices «dejando uno fuera» repitiendo la fórmula cuesta \mathcal{O}(n^2). Como T_0 y T_1 solo dependen de unas pocas sumas, todos se obtienen a la vez en \mathcal{O}(n) (resultados preliminares de THEILUMINA; véase Research problems), lo que hace el jackknife viable con millones de observaciones:

jackknife_theil <- function(y, tipo = c("T1", "T0")) {
  tipo <- match.arg(tipo); n <- length(y)
  S1 <- sum(y); S2 <- sum(y * log(y)); L <- sum(log(y))
  if (tipo == "T1") {
    T    <- S2 / S1 - log(S1 / n)
    Tloo <- (S2 - y * log(y)) / (S1 - y) - log((S1 - y) / (n - 1))
  } else {
    T    <- log(S1 / n) - L / n
    Tloo <- log((S1 - y) / (n - 1)) - (L - log(y)) / (n - 1)
  }
  sesgo <- (n - 1) * (mean(Tloo) - T)
  ee    <- sqrt((n - 1) / n * sum((Tloo - mean(Tloo))^2))
  c(T = T, sesgo = sesgo, T_corregido = T - sesgo, ee = ee)
}

round(jackknife_theil(y, "T1"), 4)  # T 0.1809  sesgo -0.0296  T_corregido 0.2106  ee 0.0858
round(jackknife_theil(y, "T0"), 4)  # T 0.2114  sesgo -0.0372  T_corregido 0.2486  ee 0.1071

Con solo seis observaciones, el error estándar es casi la mitad del índice: el ejemplo muestra por qué un valor puntual sin margen de error puede engañar.

Para intervalos de confianza, el bootstrap es la alternativa habitual. Con distribuciones asimétricas conviene usar el intervalo bootstrap-t o el BCa, mejor que el de percentiles:

library(boot)
b <- boot(datos$renta, function(d, i) theil_T0(d[i]), R = 2000)
boot.ci(b, type = c("perc", "bca"))

Con datos de encuesta, convey::svygei() ya devuelve el error estándar por linealización, teniendo en cuenta estratos y conglomerados. THEILUMINA estudia cómo predecir y corregir el sesgo (OG1), cómo construir intervalos fiables (OG2) y cómo reducir el coste del jackknife (OG3), y lo integrará todo en el paquete theil (OG4).

Errores frecuentes y buenas prácticas

  1. Confundir T_0 y T_1. Indica siempre cuál usas y comprueba la convención del paquete (en ineq, parameter = 0 es T_1).
  2. Rentas nulas o negativas. Los logaritmos fallan o los paquetes las eliminan en silencio. Decide explícitamente qué hacer con ellas (excluirlas, acotarlas o usar otro índice de la familia GE) e informa de cuántas hay.
  3. Olvidar los pesos. Con datos de encuesta, los índices sin ponderar no estiman la desigualdad de la población.
  4. Comparar sin margen de error. Una diferencia entre regiones o años solo es relevante si supera la incertidumbre del estimador. Acompaña cada índice de su error estándar o de su intervalo de confianza.
  5. Desagregar demasiado. El sesgo crece al reducirse el tamaño de cada grupo. En descomposiciones con muchos grupos pequeños, corrige el sesgo o agrupa categorías.
  6. No verificar la descomposición. Dentro + entre debe coincidir con el total; si no coincide, hay un error en los pesos o en los grupos.

## Descomposición entre y dentro de grupos

En el ejemplo, dos regiones explican el 72 % de la desigualdad total según $T_1$ y el 68 % según $T_0$. Esta función aplica las fórmulas anteriores a cualquier variable de grupo:

```r
theil_decomp <- function(y, g, w = rep(1, length(y)), tipo = c("T1", "T0")) {
  tipo <- match.arg(tipo)
  mu  <- weighted.mean(y, w)
  grp <- split(seq_along(y), g)
  res <- t(sapply(grp, function(i) {
    p   <- sum(w[i]) / sum(w)              # proporción de población
    mug <- weighted.mean(y[i], w[i])       # media del grupo
    s   <- p * mug / mu                    # proporción de renta
    Tg  <- if (tipo == "T1") theil_T1(y[i], w[i]) else theil_T0(y[i], w[i])
    if (tipo == "T1") c(p = p, s = s, T_g = Tg, dentro = s * Tg, entre = s * log(mug / mu))
    else              c(p = p, s = s, T_g = Tg, dentro = p * Tg, entre = p * log(mu / mug))
  }))
  W <- sum(res[, "dentro"]); B <- sum(res[, "entre"])
  list(grupos = res,
       resumen = c(total = W + B, dentro = W, entre = B, pct_entre = 100 * B / (W + B)))
}

g <- c("A", "A", "A", "B", "B", "B")
theil_decomp(y, g, tipo = "T1")$resumen
theil_decomp(y, g, tipo = "T0")$resumen
```

| Índice | Total | Dentro | Entre | % entre |
|---|---|---|---|---|
| $T_1$ | 0,1809 | 0,0501 | 0,1308 | 72,3 % |
| $T_0$ | 0,2114 | 0,0676 | 0,1438 | 68,0 % |

En ambos casos dentro + entre reproduce exactamente el total, lo que sirve como comprobación. Con paquetes, el mismo resultado se obtiene con `dineq::theil_decomp(y, g, w)` y `dineq::mld_decomp(y, g, w)`, con `IC2::decompGEI(y, g, w, alpha = 1)`, o con `convey::svygeidec(~y, ~g, des, epsilon = 1)` si hay diseño muestral.

## Ejemplo completo: renta por regiones

Este ejemplo simula rentas log-normales en cuatro regiones con medias y dispersiones distintas, calcula los dos índices, los descompone y representa la contribución de cada región. Los valores exactos dependen de la semilla; lo que importa es la interpretación.

```r
set.seed(2026)
regiones <- data.frame(
  region = c("Norte", "Sur", "Este", "Oeste"),
  n      = c(400, 300, 200, 100),
  media  = c(9.9, 9.5, 10.1, 9.7),   # media de log(renta)
  sd     = c(0.5, 0.7, 0.6, 0.4)
)
datos <- do.call(rbind, lapply(seq_len(nrow(regiones)), function(k) {
  with(regiones[k, ], data.frame(region = region,
                                 renta  = rlnorm(n, meanlog = media, sdlog = sd)))
}))

# Índices globales
theil_T1(datos$renta)
theil_T0(datos$renta)

# Descomposición por región
dT0 <- theil_decomp(datos$renta, datos$region, tipo = "T0")
round(dT0$grupos, 4)
round(dT0$resumen, 4)

# Contribución de cada región a la desigualdad "dentro"
library(ggplot2)
contrib <- data.frame(region = rownames(dT0$grupos),
                      dentro = dT0$grupos[, "dentro"])
ggplot(contrib, aes(reorder(region, dentro), dentro)) +
  geom_col(fill = "#E07B20") + coord_flip() +
  labs(x = NULL, y = "Contribución a T0 (dentro de regiones)")
```

Cómo leer el resultado:

- `pct_entre` indica qué parte de la desigualdad se debe a que las regiones tienen rentas medias distintas. Una política de convergencia regional solo puede actuar sobre esa parte.
- La columna `dentro` muestra qué regiones aportan más desigualdad interna. Depende tanto de su desigualdad propia (`T_g`) como de su tamaño (`p`).
- Si $T_1$ y $T_0$ dan mensajes distintos, la desigualdad se concentra en colas diferentes: $T_1$ reacciona a la parte alta y $T_0$ a la parte baja.

## Ejemplo: descomposición por sexo

En este ejemplo, la brecha entre mujeres y hombres explica alrededor del 23 % de la desigualdad total; el 77 % restante se debe a la desigualdad dentro de cada sexo. Los datos son diez rentas (en miles de euros), cinco de mujeres y cinco de hombres:

```r
renta <- c(12, 15, 18, 22, 30,   # mujeres
           16, 20, 25, 35, 50)   # hombres
sexo  <- rep(c("Mujer", "Hombre"), each = 5)

d1 <- theil_decomp(renta, sexo, tipo = "T1")
d0 <- theil_decomp(renta, sexo, tipo = "T0")
round(d0$grupos, 4)
round(rbind(T1 = d1$resumen, T0 = d0$resumen), 4)
```

| Grupo | Renta media | % población | % renta | $T_1$ del grupo | $T_0$ del grupo |
|---|---|---|---|---|---|
| Mujeres | 19,4 | 50 % | 39,9 % | 0,0502 | 0,0502 |
| Hombres | 29,2 | 50 % | 60,1 % | 0,0833 | 0,0833 |

| Índice | Total | Dentro | Entre (brecha de género) | % entre |
|---|---|---|---|---|
| $T_1$ | 0,0906 | 0,0701 | 0,0205 | 22,6 % |
| $T_0$ | 0,0875 | 0,0667 | 0,0208 | 23,7 % |

Cómo leerlo:

- La parte **entre** mide cuánta desigualdad desaparecería si mujeres y hombres tuvieran la misma renta media. Es la medida de la brecha de género que ofrecen los índices de Theil.
- La parte **dentro** indica que, aun cerrando la brecha, quedaría la mayor parte de la desigualdad, sobre todo entre los hombres (índice del grupo 0,083 frente a 0,050).
- Con datos de encuesta, la misma descomposición con su error estándar se obtiene con `convey::svygeidec(~renta, ~sexo, des, epsilon = 0)`. Es lo que permite decir si la brecha ha cambiado de verdad entre dos años.

La variable de grupo puede ser cualquier otra: discapacidad, nacionalidad, nivel educativo, o cruces como sexo × región (`interaction(sexo, region)`). Cuantos más grupos, más pequeños son y mayor es el sesgo, como se explica en la sección siguiente.

## Sesgo y precisión

Los estimadores muestrales de $T_0$ y $T_1$ tienen sesgo, que suele ser a la baja y es mayor en muestras pequeñas y con distribuciones de cola pesada. Por eso no deberían publicarse sin una medida de su precisión. El jackknife da a la vez una estimación del sesgo y del error estándar:

$$
\widehat{\text{sesgo}} = (n-1)\,(\bar T_{(\cdot)} - \hat T), \qquad
\tilde T = \hat T - \widehat{\text{sesgo}}, \qquad
\widehat{\text{Var}} = \frac{n-1}{n}\sum_i \big(\hat T_{(i)} - \bar T_{(\cdot)}\big)^2
$$

Calcular los $n$ índices «dejando uno fuera» repitiendo la fórmula cuesta $\mathcal{O}(n^2)$. Como $T_0$ y $T_1$ solo dependen de unas pocas sumas, todos se obtienen a la vez en $\mathcal{O}(n)$ (resultados preliminares de THEILUMINA; véase [Research problems](../research.qmd)), lo que hace el jackknife viable con millones de observaciones:

```r
jackknife_theil <- function(y, tipo = c("T1", "T0")) {
  tipo <- match.arg(tipo); n <- length(y)
  S1 <- sum(y); S2 <- sum(y * log(y)); L <- sum(log(y))
  if (tipo == "T1") {
    T    <- S2 / S1 - log(S1 / n)
    Tloo <- (S2 - y * log(y)) / (S1 - y) - log((S1 - y) / (n - 1))
  } else {
    T    <- log(S1 / n) - L / n
    Tloo <- log((S1 - y) / (n - 1)) - (L - log(y)) / (n - 1)
  }
  sesgo <- (n - 1) * (mean(Tloo) - T)
  ee    <- sqrt((n - 1) / n * sum((Tloo - mean(Tloo))^2))
  c(T = T, sesgo = sesgo, T_corregido = T - sesgo, ee = ee)
}

round(jackknife_theil(y, "T1"), 4)  # T 0.1809  sesgo -0.0296  T_corregido 0.2106  ee 0.0858
round(jackknife_theil(y, "T0"), 4)  # T 0.2114  sesgo -0.0372  T_corregido 0.2486  ee 0.1071
```

Con solo seis observaciones, el error estándar es casi la mitad del índice: el ejemplo muestra por qué un valor puntual sin margen de error puede engañar.

Para intervalos de confianza, el bootstrap es la alternativa habitual. Con distribuciones asimétricas conviene usar el intervalo bootstrap-t o el BCa, mejor que el de percentiles:

```r
library(boot)
b <- boot(datos$renta, function(d, i) theil_T0(d[i]), R = 2000)
boot.ci(b, type = c("perc", "bca"))
```

Con datos de encuesta, `convey::svygei()` ya devuelve el error estándar por linealización, teniendo en cuenta estratos y conglomerados. THEILUMINA estudia cómo predecir y corregir el sesgo (OG1), cómo construir intervalos fiables (OG2) y cómo reducir el coste del jackknife (OG3), y lo integrará todo en el paquete **theil** (OG4).

## Errores frecuentes y buenas prácticas

1. **Confundir $T_0$ y $T_1$.** Indica siempre cuál usas y comprueba la convención del paquete (en `ineq`, `parameter = 0` es $T_1$).
2. **Rentas nulas o negativas.** Los logaritmos fallan o los paquetes las eliminan en silencio. Decide explícitamente qué hacer con ellas (excluirlas, acotarlas o usar otro índice de la familia GE) e informa de cuántas hay.
3. **Olvidar los pesos.** Con datos de encuesta, los índices sin ponderar no estiman la desigualdad de la población.
4. **Comparar sin margen de error.** Una diferencia entre regiones o años solo es relevante si supera la incertidumbre del estimador. Acompaña cada índice de su error estándar o de su intervalo de confianza.
5. **Desagregar demasiado.** El sesgo crece al reducirse el tamaño de cada grupo. En descomposiciones con muchos grupos pequeños, corrige el sesgo o agrupa categorías.
6. **No verificar la descomposición.** Dentro + entre debe coincidir con el total; si no coincide, hay un error en los pesos o en los grupos.
